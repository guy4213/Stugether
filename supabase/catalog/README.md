# Course catalog data

Real course lists and syllabus topics, imported automatically from public sources. Nothing here is
written by hand or generated by a model. Every topic is a phrase taken from a published source, and
`course_topics.source` / `source_ref` / `source_url` record which one.

## Files

| File               | Produced by                       | Content                                                                                     |
| ------------------ | --------------------------------- | ------------------------------------------------------------------------------------------- |
| `hit.json`         | `scripts/catalog/hit.mjs`         | HIT courses per department from the faculty handbooks, plus topics where HIT publishes them |
| `hit-archive.json` | `scripts/catalog/hit-archive.mjs` | Topics from HIT's own older syllabus books (Internet Archive copies), keyed by course code  |
| `hit-courses.json` | `scripts/catalog/enrich.mjs`      | `hit.json` with topics filled in from the best available source                             |
| `.cache/`          | all of the above (git-ignored)    | Raw downloads                                                                               |

## Topic sources, in priority order

1. **hit_current**: the current HIT handbook's course summary (`official_description`, verified).
2. **hit_archive**: HIT's own archived syllabus, matched by course code and confirmed by name
   (`official_syllabus`, verified).
3. **hit_archive_name**: HIT's own archived syllabus matched by name, for renumbered courses.
   Design was renumbered in 2013-14, and the 2012 design book's font garbles its codes. Only a
   course for the same audience matches (`official_syllabus`, draft).
4. **technion**: the same standard course at the Technion
   ([technion-sap-info-fetcher](https://github.com/michael-maltsev/technion-sap-info-fetcher)),
   matched by normalized name (`equivalent_course`, draft).
5. **braude**: the same course at Braude College (per-course syllabus PDFs; `equivalent_course`,
   draft).
6. **openu**: the same course at the Open University (`equivalent_course`, draft).

Equivalent-course matching is deliberately strict: it skips projects, seminars and studios, and it
does not extend one-word names. A course without a confident match keeps an empty syllabus rather
than borrowing a wrong one.

Checked and not used:

- HIT's Rashim syllabus portal: needs its request signing.
- Hebrew University's course search: blocked by its firewall for scripts.
- Bezalel, which has only a few text-extractable years.
- Shenkar, which has abstracts only.
- Sapir, Hadassah and Haifa, which are behind anti-bot walls.

Topic paragraphs are split by `scripts/catalog/lib/topics.mjs`. This is deterministic: items come
from numbered lists, `;`, and `,`, and `heading: a, b, c` becomes a topic with subtopics.

## Re-importing (once per academic year)

```bash
node scripts/catalog/hit.mjs
node scripts/catalog/hit-archive.mjs        # needs pdftotext (poppler) on PATH
node scripts/catalog/enrich.mjs             # downloads Technion, Braude (pdftotext) and Open University data
node scripts/catalog/to-sql.mjs YYYYMMDDNNNNNN_hit_catalog_<year>.sql
npm run db:test
```

`to-sql.mjs` writes a new migration. Never edit an applied one. The migration upserts courses by
`(institution_id, code)` and only adds topics to courses that have none, so topics an admin edited
are never overwritten.

## Notes

- Only facts are stored: names, numbers and topic titles. No lecturer names and no copied prose
  beyond a short course description.
- HIT's terms of use restrict commercial reuse of site content without written consent. Get that
  consent before a commercial launch.
- The requests are polite: `robots.txt` is honoured, requests are spaced out, and downloads are cached.
